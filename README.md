## 功能简介
Bookmark-X 是一个 IntelliJ 插件，提供以下功能：

- 分组管理书签，支持快速切换代码位置  
- 支持修改行号，拖拽 GutterIcon 快速定位  
- 导出书签，可选择目录及文件名
