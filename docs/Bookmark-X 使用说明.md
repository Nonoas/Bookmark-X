# Bookmark-X 使用说明

> 本文可直接作为项目 Wiki 使用。截图位置已用「截图占位」标出，替换为实际图片即可。

## 1. 插件简介

Bookmark-X 是一个 IntelliJ Platform 插件，用于增强 IDE 原生书签能力。它适合在阅读复杂代码、梳理调用链、记录重点逻辑时使用，可以把代码位置按分组管理，并通过快捷键在同一分组内快速跳转，减少在多层嵌套代码中来回查找的成本。

主要能力：

- 创建代码书签，记录文件、行号、名称和说明。
- 按分组组织书签，支持多级分组。
- 在当前激活分组内快速切换上一个/下一个书签。
- 在编辑器 Gutter 区域显示书签图标。
- 支持编辑、删除、拖拽排序、批量调整行号。
- 支持书签导入和导出，便于备份或迁移。
- 支持书签描述悬浮展示或右侧分割面板展示。

## 2. 安装与启用

### 2.1 从插件市场安装

1. 打开 IntelliJ IDEA。
2. 进入 `Settings / Preferences > Plugins`。
3. 在 Marketplace 中搜索 `Bookmark-X`。
4. 点击安装，安装完成后按 IDE 提示重启。
5. 重启后，在 IDE 工具窗口栏中找到 `Bookmark-X`。

【截图占位 02：插件市场安装页面】

建议截图内容：`Settings / Preferences > Plugins > Marketplace` 中搜索 `Bookmark-X` 的结果，能看到插件名称和安装按钮。

### 2.2 从本地插件包安装

如果使用的是本地构建的插件包：

1. 打开 `Settings / Preferences > Plugins`。
2. 点击齿轮图标。
3. 选择 `Install Plugin from Disk...`。
4. 选择构建出来的插件压缩包。
5. 按 IDE 提示重启。

建议截图内容：插件设置页右上角齿轮菜单展开，突出显示 `Install Plugin from Disk...` 入口。

## 3. 打开 Bookmark-X 工具窗口

安装并重启后，在 IDE 工具窗口栏中点击 `Bookmark-X` 即可打开书签管理面板。面板以树形结构展示当前项目的全部书签，根节点通常是当前项目名称。

工具窗口中可以完成以下操作：

- 查看所有书签和分组。
- 单击分组，激活该分组。
- 双击书签，跳转到对应代码位置。
- 右键书签或分组，进行编辑、删除、添加分组等操作。
- 拖拽书签或分组，调整顺序或移动到其他分组。

## 4. 创建书签

Bookmark-X 支持两种常用创建方式。

### 4.1 使用快捷键创建

1. 在编辑器中把光标移动到需要标记的代码行。
2. 按 `Alt + Shift + D`。
3. 在弹出的“输入书签信息”窗口中填写名称和描述。
4. 点击 `OK` 保存。

如果当前已经在 Bookmark-X 工具窗口中选中了某个分组，新书签会创建到该激活分组下。

【截图占位 05：创建书签弹窗】

建议截图内容：在代码编辑器中按 `Alt + Shift + D` 后弹出的创建窗口，显示“名称”“所在分组”“描述”等字段。

### 4.2 通过 Gutter 右键创建

1. 在代码编辑器左侧行号区域右键。
2. 选择 `Add Bookmark-X`。
3. 在弹窗中确认书签名称和描述。
4. 点击 `OK` 保存。

通过 Gutter 创建时，Bookmark-X 会把当前行文本作为描述的默认内容，适合快速标记重点代码。

【截图占位 06：Gutter 右键菜单】

建议截图内容：在代码行号区域右键后出现的菜单，突出显示 `Add Bookmark-X`。

## 5. 查看与跳转书签

创建书签后，Bookmark-X 会在编辑器左侧 Gutter 区域显示书签图标，并在工具窗口中新增对应书签节点。

常见跳转方式：

- 在 Bookmark-X 工具窗口中双击书签。
- 点击代码行左侧的 Bookmark-X 图标。
- 使用快捷键在当前分组内跳转：
  - `Alt + Shift + →`：跳转到当前分组中的下一个书签。
  - `Alt + Shift + ←`：跳转到当前分组中的上一个书签。

注意：快捷键只在当前激活分组内循环切换，不会自动遍历下级分组中的书签。单击某个分组可以把它设为当前激活分组。

## 6. 分组管理

分组用于把一组相关书签组织在一起，例如“初始化流程”“核心业务逻辑”“问题排查路径”“待重构位置”等。

### 6.1 添加分组

1. 在 Bookmark-X 工具窗口中右键根节点或任意分组。
2. 选择 `添加分组`。
3. 输入分组名称和描述。
4. 点击 `OK` 保存。

如果右键的是分组，新分组会添加到该分组下；如果右键的是书签，新分组会添加到该书签所在分组下。

【截图占位 09：添加分组菜单】

建议截图内容：在工具窗口的根节点或分组节点上右键，菜单中显示 `添加分组`。

### 6.2 调整书签顺序和归属

在 Bookmark-X 工具窗口中，可以直接拖拽书签或分组：

- 将书签拖到同一分组的不同位置，可调整阅读顺序。
- 将书签拖到其他分组，可改变书签归属。
- 将分组拖到其他分组，可整理多级结构。

## 7. 编辑、删除与调整行号

### 7.1 编辑书签或分组

在 Bookmark-X 工具窗口中右键书签或分组，选择 `编辑`，可修改名称和描述。

编辑书签时，还可以修改行号。行号从 1 开始显示，必须在当前文件的有效行数范围内。

【截图占位 11：编辑书签弹窗】

建议截图内容：右键书签选择 `编辑` 后的弹窗，显示名称、行号、描述字段，以及描述区域右上角的预览按钮。

### 7.2 删除书签或分组

右键书签或分组，选择 `删除`，确认后即可删除。

删除分组时，该分组下的书签和子分组也会一并删除。执行前请确认不再需要这些书签。

【截图占位 12：删除确认弹窗】

建议截图内容：右键书签或分组选择删除后出现的确认窗口。

### 7.3 批量调整行号

当代码发生整体插入或删除后，多个书签的行号可能需要一起偏移。此时可以使用批量调整行号：

1. 在 Bookmark-X 工具窗口中多选多个书签。
2. 右键选中项。
3. 选择 `批量调整行号`。
4. 输入调整值：
   - 正数表示整体向后移动，例如 `5` 表示每个书签行号加 5。
   - 负数表示整体向前移动，例如 `-3` 表示每个书签行号减 3。
5. 点击确认。

该菜单只会在“多选内容全部都是书签”时出现。

建议截图内容：多选多个书签后右键，菜单中显示 `批量调整行号`；另截一张调整值输入窗口。

## 8. 书签描述展示

Bookmark-X 支持为书签和分组填写描述。描述可以用于记录：

- 这段代码的作用。
- 阅读时的思考和结论。
- 后续待处理事项。
- 与其他代码位置的关系。

描述支持两种展示方式：

- 气泡框：鼠标悬停在书签树节点上时弹出描述。
- 分割面板：在工具窗口右侧固定展示当前选中节点的描述。

可以在插件设置中切换展示方式。

## 9. 导入与导出

Bookmark-X 支持将当前项目的书签导出为 JSON 文件，也支持从 JSON 文件导入。

### 9.1 导出书签

1. 打开 Bookmark-X 工具窗口。
2. 点击工具窗口顶部的导出按钮。
3. 选择保存目录和文件名。
4. 导出完成后，IDE 会显示成功通知。

导出的路径中会使用 `$PROJECT_DIR$` 表示当前项目目录，便于在同一项目的不同机器之间迁移。

【截图占位 16：导出按钮和保存窗口】

建议截图内容：Bookmark-X 工具窗口顶部的导出按钮，以及选择保存位置的文件保存窗口。

### 9.2 导入书签

1. 打开 Bookmark-X 工具窗口。
2. 点击工具窗口顶部的导入按钮。
3. 选择之前导出的 `.json` 文件。
4. 导入后，Bookmark-X 会重新加载书签树。

导入时，插件会把 `$PROJECT_DIR$` 替换为当前项目路径。

## 10. 插件设置

进入 `Settings / Preferences > Tools > Bookmark-X` 可以调整插件行为。

常用设置包括：

- 语言：切换插件界面语言，修改后通常需要重启 IDE 生效。
- 书签描述展示方式：选择气泡框或分割面板。
- 鼠标悬停显示标签描述：开启后，鼠标停留在书签树节点上会显示描述。
- 描述弹框延迟：设置悬停多久后显示描述。
- MCP 服务：开启或关闭 Bookmark-X 的 MCP 服务，并设置端口和密码。

普通用户主要关注语言和描述展示方式即可；MCP 服务适合需要让外部工具或 AI 助手读取、创建、更新书签的场景。

## 11. 推荐使用方式

### 11.1 按阅读路径建分组

阅读一个复杂流程时，可以先创建一个顶层分组，例如“登录流程阅读”。然后按阅读顺序创建书签：

1. 入口 Controller。
2. 参数校验。
3. 核心 Service。
4. 数据访问。
5. 异常处理。
6. 返回结果。

之后使用 `Alt + Shift + →` 就可以按顺序复盘整个流程。

### 11.2 用描述记录上下文

书签名称建议简短，例如“入口方法”“权限校验”“组装返回值”。详细说明可以写在描述里，例如：

```text
这里负责将请求参数转换为内部查询条件。
注意 userType 为空时会走默认分支，排查权限问题时需要先看这里。
```

### 11.3 改动代码后及时调整行号

如果代码变动较大，书签可能偏离原本位置。可以通过编辑单个书签修正行号，也可以多选书签后使用 `批量调整行号`。

## 12. 常见问题

### 12.1 为什么按快捷键没有反应？

请确认：

- 当前焦点在代码编辑器中。
- 当前项目已启用 Bookmark-X。
- 快捷键没有被其他插件或 IDE 设置占用。
- 可以在 `Settings / Preferences > Keymap` 中搜索 `Bookmark-X` 查看或重新绑定快捷键。

### 12.2 为什么上一个/下一个书签没有跳到预期位置？

`Alt + Shift + ←/→` 只会在当前激活分组内循环跳转。请先在 Bookmark-X 工具窗口中单击目标分组或分组内任意书签，再使用快捷键。

### 12.3 为什么批量调整行号菜单不显示？

该菜单只在多选内容全部都是书签时出现。如果选中了分组，或者只选中了一个书签，菜单不会显示。

### 12.4 为什么导入后书签不能跳转？

请确认导入的 JSON 来自同一个项目，或者文件路径在当前项目中仍然存在。Bookmark-X 会处理 `$PROJECT_DIR$`，但如果文件已移动、重命名或删除，书签可能无法跳转到正确位置。
